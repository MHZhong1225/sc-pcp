# Public documentation

This directory contains the implementation-facing documentation that ships
with the source release.

- [Method definition and claim boundary](final_method.md)
- [Coverage, width, selection rate, and uncertainty definitions](evaluation_metrics.md)

Frozen experiment protocols, paper narratives, result tables, figure
portfolios, clinical-data inventories, and negative-result records are kept in
the local Git-ignored `internal/docs/` archive. They are intentionally not
part of the public code release.
